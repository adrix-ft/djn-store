## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (version `v18.0.0` or higher recommended)
- `npm` or `pnpm`

### 1. Clone the Repository
```bash
git clone https://github.com/djntechofficial-art/DJN-Website.git
cd DJN-Website
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch Development Server
```bash
npm run dev
```
The application will start on **`http://localhost:3000`** (or your local Vite network address).

### 4. Build for Production
```bash
npm run build
```
Generates production-optimized static assets in the `dist/` directory.
